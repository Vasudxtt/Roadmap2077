# 10xThink — AI Career Platform

## 🚀 How to Run

1. Make sure you have **Node.js** installed (v18+ recommended)

2. Install dependencies (only needed once):
```
npm install
```

3. Start the server:
```
node server.js
```

4. Open your browser and go to:
```
http://localhost:3000
```

That's it! The API key is already built into server.js.

## ✅ Features
- Career Roadmap Generator (AI-powered)
- Student Stream Guidance + Quiz
- Competitive Exam Planner (JEE, NEET, UPSC…)
- Project Hub with AI guidance
- Resume Analyzer + Generator
- Unlimited AI Chat
